📖 HAMGIS 使用说明

欢迎使用HAMGIS测亩软件数据管理中心！本页面提供强大的数据导出功能，支持多种专业格式。

🎯 主要功能

  • 查看所有测量项目的统计信息
  • 浏览测量记录列表
  • 导出数据为多种专业格式
  • 支持Excel分析和GIS软件导入

📤 数据导出格式

📊
CSV 项目汇总
每个项目一行，包含面积、海拔、点数等信息，适合在Excel中进行数据分析和统计
📍
CSV 详细点位
每个采集点一行，包含完整的经纬度坐标和海拔信息，适合坐标验证和轨迹分析
📄
JSON 完整数据
包含所有字段和元数据的完整数据结构，适合数据备份和系统间迁移
🗺️
GeoJSON 标准
符合RFC 7946标准的GIS格式，可直接导入ArcMap、QGIS等专业GIS软件进行地图制作和空间分析

📝 使用步骤

  • 步骤1: 在手表端完成测量后，数据会自动同步到手机
  • 步骤2: 在"数据导出"区域选择需要的导出格式
  • 步骤3: 点击"导出选中格式"按钮
  • 步骤4: 文件会自动下载到浏览器的下载文件夹
  • 步骤5: 使用相应软件打开导出的文件

💡 使用建议

  • Excel分析: 使用CSV项目汇总格式，可以快速进行面积统计、数据筛选和图表制作
  • 坐标验证: 使用CSV详细点位格式，可以逐点检查GPS坐标的准确性
  • 数据备份: 使用JSON完整数据格式，可以保存所有原始数据，防止数据丢失
  • GIS分析: 使用GeoJSON标准格式，可以在专业GIS软件中进行空间分析、地图制作和可视化

🗺️ GeoJSON在GIS软件中的使用

ArcMap/ArcGIS导入步骤:

  • 打开ArcMap或ArcGIS Pro
  • 点击"添加数据" → 选择导出的.geojson文件
  • 数据会自动显示为多边形图层
  • 可以查看属性表，包含面积、海拔等所有信息

QGIS导入步骤:

  • 打开QGIS
  • 拖拽.geojson文件到QGIS窗口
  • 或使用"图层" → "添加图层" → "添加矢量图层"
  • 选择导出的.geojson文件即可

📊 数据字段说明

CSV项目汇总包含字段:

  • ID、项目名称、测量时间
  • 面积（平方米、亩、公顷）
  • 周长、采集点数、GPS精度
  • 海拔数据（平均、最高、最低、高差）
  • 项目状态

⚠️ 注意事项

  • CSV文件在Excel中打开时，如果中文显示乱码，请使用"数据" → "从文本/CSV导入"，并选择UTF-8编码
  • GeoJSON文件使用WGS84坐标系（EPSG:4326），与GPS采集的坐标系一致
  • 导出的文件名包含时间戳，不会覆盖之前的导出文件
  • 建议定期导出数据进行备份，防止数据丢失
